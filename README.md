Bem-vindo ao repositório do site oficial da **IMDE**. Este projeto é um portal corporativo estático projetado para apresentar nossas soluções inovadoras de recrutamento, depoimentos de clientes e recursos da plataforma. 

Construído com tecnologias web nativas, o site foca em performance, acessibilidade e uma identidade visual forte baseada no **Sistema de Design Mondrian**.

---

## ✨ Destaques do Projeto

*   🎨 **Design System Mondrian:** Estilização centralizada e consistente em todas as páginas através do nosso arquivo `styles.css`.
*   🧩 **Componentização Dinâmica:** Cabeçalhos, rodapés e menus de navegação são injetados via JavaScript (`components.js`), facilitando a manutenção global.
*   🌍 **Suporte a Múltiplos Idiomas:** Sistema de internacionalização (i18n) integrado diretamente nos componentes JS.
*   🚀 **Alta Performance:** Estrutura enxuta sem dependências pesadas, garantindo carregamento rápido.


## 📈 Nossas Soluções

O site destaca três pilares principais de serviços da IMDE:
1. **Lean Recruiting:** Processos ágeis para contratações eficientes.
2. **Talent Recruiter:** Ferramentas avançadas para headhunters e recrutadores.
3. **Talent Developer:** Plataforma focada no desenvolvimento e retenção de talentos.
